# WaterLab

WaterLab is a static virtual chemistry laboratory for junior and degree college students learning water-sample analysis.

## Publish as a public website

This project has no build step. Publish the folder containing `index.html` with any static hosting provider.

### GitHub Pages

1. Create a GitHub repository and upload `index.html` and this `README.md`.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. GitHub will provide the public website link.

### Netlify

1. Open Netlify and choose **Add new site > Deploy manually**.
2. Drag the project folder into the upload area.
3. Netlify will provide a public `netlify.app` link.

### Custom domain

After publishing, connect a domain such as `waterlab.in` from the host's domain settings. Replace the host-provided link with the custom domain when sharing the site.

## Important note

The experiments and readings are educational simulations. The reference table uses commonly taught BIS IS 10500:2012 drinking-water values; institutions should verify current standards and laboratory procedures before using them for formal practical work.
